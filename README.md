# Student Marks Calculator

This is a Python project to calculate student marks and grades based on input marks for different subjects.

## Features
- Enter marks for multiple subjects
- Calculates total marks and percentage
- Assigns grade based on percentage
- User-friendly command line interface

## How to Use
1. Download or clone the repository.
2. Run the Python file `student_marks_calculator.py`.
3. Follow the prompts to enter marks.
4. See the results (total, percentage, grade).
